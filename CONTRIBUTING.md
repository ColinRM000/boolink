# Contributing to BooLink

BooLink is early in development. Start by reading `AGENTS.md`, the initial architecture, and the
implementation plan. Discuss changes to public contracts, transports, credential handling, or
package boundaries before implementing them.

For a local check:

```bash
pnpm install
pnpm check
```

Use Conventional Commits where practical. Pull requests should explain the user-facing effect,
security implications, verification performed, and any deferred work.
